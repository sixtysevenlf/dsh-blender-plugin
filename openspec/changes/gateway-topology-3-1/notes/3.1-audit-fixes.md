# 3.1.0 缺陷审计与修复（2026-11-13）

对本 change 已实现的主体做一次"规格 ↔ 代码 ↔ 测试"对照，产出 5 CRITICAL / 12 WARNING /
5 SUGGESTION，并逐条修复。每条都先写失败测试再改实现，规格文本在同一次改动里补齐。

## CRITICAL

| 问题 | 复现 | 修复 |
| --- | --- | --- |
| `dry_run=true` 无会话被 409 | `blender_op(op="transform", args={...}, dry_run=true)` 无 session | `/plan` 把 `args.dry_run===true` 视为只读，host 不再写 `write_scope`；session-read op 仍要求会话 |
| render 无分辨率时假成功 | `blender_run(kind="render")` 不传 `resolution` | prelude 无条件 `s=bpy.context.scene`；legacy 与 headless 都带 `--python-exit-code 2` |
| `see full=true` 不守 1024 且无提示 | `blender_see(viewpoint="viewport", full=true)` | 整窗 `screen.screenshot`（`method=screenshot_window`）或指定 `area`，两条路径都缩到 1024 长边并在回执说明来源与黑帧风险 |
| headless `preload`/`out_json` 静默无效 | `blender_run(kind="headless", preload=["numpy"], out_json="…")` | 参数生效；未知/非法值 `invalid_params`；`out_json` 写失败 → `out_json_write_failed` |
| py 超时释放锁 | `POST /act` `timeoutMs=1500` + `time.sleep(6)` | 超时返回 409 `py_still_running` 并保留 `activePy`，迟到的完成再释放 |

## WARNING

- `sequence` 的 `viewport` 忽略 `from`/`look_at` → 现在显式拒绝。
- `sequence.images` 混用字符串与 attachment ref → 统一返回 ref。
- `wait_ms` 因 py_busy 先于租约判定而永不生效 → 带 `wait_ms` 时把互斥交给 `beginPy` 排队。
- 同一 holder 的第二个 py 覆盖锁 → 报 `py_busy` 并保留原 holder。
- 空 `instanceId` 的人类暂停暂停所有实例 → 只暂停来事件的实例。
- attach 把 virtual-gui 实例变成 user-gui → 返回 `session_unavailable`，不再改 kind。
- `/doctor` 曾顶到 3.055 s（预算 3 s）→ addon 探测 2.5 s → 2.0 s。
- `get_polyhaven_categories` 绕过 `online_access` → 补 `network=True` 与网络策略测试。
- `has()` 把显式 `false` 当有值 → `camera:false` 映射为场景相机。
- frames 字符串 `"1-2-3"`、`"-5--1"` 被静默曲解 → 严格正则，`start<=end`，否则 `invalid_params`。
- `inspect help` 把被 gate 关闭的命令列进"可执行" → 分段列出并标注 gate。
- `/addon` 升级不校验 Origin、同 `instanceId` 无条件顶替 → Origin 白名单 + `instance_in_use`。

## delta 收敛（归档不再撞重名）

主 spec（`openspec/specs/blender/{gateway,sessions}/spec.md`）早已在之前的同步里被本 change 写过一遍，
delta 里再以 `## ADDED` 声明同名 requirement 会让 `openspec archive` 拒绝。处理方式：

- 与主 spec 逐字相同的 requirement 从 delta 移除（它们已经入库，不是本次新增）；
- 本次真正改动过的共 7 条，其中 6 条改挂 `## MODIFIED Requirements`：gateway 的
  `Reconnect replaces a stale connection`；sessions 的 `Writes are coordinated by intra-session scope
  grants`、`Session mutations require an exclusive grant`、`Human edits take priority`、
  `virtual-gui is Gateway-managed and user-invisible`、`see preview options respect the model pixel bounds`。
- `see preserves the user viewport and publishes presence` 只有场景标题措辞差异（MODIFIED 会整块替换，
  校验拒绝丢场景），按主 spec 原样保留，不进 delta。

结果：`openspec validate gateway-topology-3-1` → `valid`，无 INFO。
