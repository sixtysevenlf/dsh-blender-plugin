# 给第三方的安装清单（照着走就行）

> 目标：**从零**把 `@dsh-external/dsh-blender-plugin` 装到自己的机器上并完成验收。全程约 10–15 分钟。
> 验收判据：**GUI 路线 = `curl -sS http://127.0.0.1:9877/doctor` 回 `kind=ok`**；
> **纯无头路线**（不装 addon）= `blender_rt_worker(op="start")` + `op="see"` 回一帧图（doctor 的 bpy 往返不可达属预期）。
> 每一步都有**自检命令**：卡住就先跑自检，再往下走。

> **当前版本口径（2026-10-28）**：插件 **v2.6.2** · **15 个模型工具** · plan catalog **34 family / 228 op** ·
> Blender 侧 addon **v1.10**（protocol **11**）· 后端 `127.0.0.1:9877` / addon `127.0.0.1:9876`。
> **GUI 首选**：有 GUI 最方便；没有 GUI 时用交互式无头（`blender_rt_worker`：start/exec/see/watch/reset）同样能建模、看图。

## 0. 前置（5 条，缺一不可）

| # | 需要什么 | 怎么确认 |
|---|---|---|
| 1 | **DSH**（本插件是 DSH 插件，装在 DSH 的 profile 里） | `dsh --version` 有输出 |
| 2 | **Blender 4.x / 5.x**（GUI 版最方便；无 GUI 时交互式无头也可用） | 能打开 Blender 窗口，或能跑 `blender -b` |
| 3 | **Blender 侧 addon** —— 只支持本仓 [`addon/dsh_blender_bridge.py`](../addon/dsh_blender_bridge.py)（**v1.10+ / protocol 11**） | 见 §2（旧 `MCP for Blender` 自 v2.3 起不再支持） |
| 4 | **Node** | `node -v` 有输出 |
| 5 | 端口 **9877**（后端）/ **9876**（addon）空闲 | 见 §5 排查 |

## 1. 拿到插件

~~~bash
git clone <本仓地址> dsh-blender-plugin && cd dsh-blender-plugin
ls lib/index.js        # ← 有这个文件就**不用构建**（本仓已提交 lib/）
~~~

> **构建是可选的**：只有你要改 `src/` 时才需要
> `DSH_CHECKOUT=/path/to/dsh-harness bash scripts/build.sh`（要指向一个 DSH 源码 checkout）。

## 2. 装 Blender 侧 addon（二选一）

**A. 本仓附带版（唯一支持）**

1. Blender → `Edit ▸ Preferences ▸ Add-ons ▸ Install...` → 选 `addon/dsh_blender_bridge.py`
2. 勾选启用 **DSH Blender Bridge**（addon **v1.10** / protocol 11）
3. 3D 视图按 `N` →「DSH Blender Bridge」面板 → **Connect**（端口 9876）

> **自检**：`blender_rt_cmd(name="get_addon_info")` → `addon_version=[1,10]`、`protocol=11`、capabilities 含
> `get_activity_state / get_selection / get_collections / send_*_to_dsh`。

## 3. 装进 DSH

1. 软链（或拷贝）本目录到 `<你的 profile>/node_modules/@dsh-external/dsh-blender-plugin`
2. 该 profile 的 `package.json`：
   - `dependencies` 加 `"@dsh-external/dsh-blender-plugin": "link:<本目录绝对路径>"`
   - `dsh.profile.bundles` 加 `"@dsh-external/dsh-blender-plugin"`
3. 预演配置：`dsh --profile <profile> --dump-config`（能看到本插件即成功）
4. **重启 DSH**（插件是启动时装载的模块）
5. 重启后**会话技能目录会自动多出 `blender-modeling`**（v2.2.0 起随包注册为 bundled skill，无需下载 / 软链）；让模型用 `skill` 加载它即可确认
6. **（v2.3 起，建议）Blender 原生选中 → DSH**：确认 addon 是 **v1.10+**（`blender_rt_cmd get_addon_info` 看 `addon_version`），
   在视口里选中物体 → `N` ›「DSH Blender Bridge」› **Selection → DSH** ›「发送选中到 DSH」→ DSH 当前会话草稿应出现对象名。
   回执排错看 `curl -sS http://127.0.0.1:9877/host/selection/latest` 的 `last_consume`。
7. **（addon v1.10 起）暂停 AI 操作**：N 面板顶部按钮；暂停后写操作被拒绝、只读仍可用，恢复只能在 Blender 里点。

## 4. 起 Blender 并验证（**验收判据**）

> **GUI 路线**：`doctor` → `kind=ok` 是唯一判据；**纯无头路线**（不装 addon）：`rt_worker(start)` + `see` 出图即可。

~~~bash
# 推荐：一键拉起 GUI Blender + 自动启用 addon（幂等）
blender_viewport(op="launch")

# 验收（全绿才算装好）：
curl -sS http://127.0.0.1:9877/health      # 后端活着
curl -sS http://127.0.0.1:9877/doctor      # ⭐ GUI 路线判据：kind=ok
blender_rt_plan(op="catalog")              # 34 family / 228 op
blender_rt_commands()                      # addon 39 条命令 + 5 个集成状态
~~~

> **没有 GUI 也能验收**（交互式无头；不依赖 Blender 窗口；此时 doctor 的 bpy 往返不可达属预期）：
> ~~~text
> blender_rt_worker(op="start")            # 持久 blender -b（冷启动 ~2s）
> blender_rt_worker(op="see", from="4,-4,3", look_at="0,0,1")   # 出图 ~50–100ms
> ~~~
> v2.3 起 DSH 侧**视口面板已删除**（改用 Blender 原生选中 + N 面板发送；见 §3 第 6 步）。

## 5. 卡住了先看这张表

| 回执 / 现象 | 含义 | 处置 |
|---|---|---|
| `blender-unreachable` | Blender 没跑，或 addon 没 Connect | `blender_viewport(op="launch")`；或人工按 `N` → Connect；纯无头改用 `blender_rt_worker` |
| `blender-unreachable`，且 `/doctor` 的 `addon.kind` 不是 `ok` | addon 不是本仓 v1.10+（旧 `MCP for Blender` / category-action 自 v2.3 起不支持）。**自 v2.3 起不再做协议探测**，所以没有 `handshake-stale` 这种「缓存成 fallback」的状态 | 停用旧 addon → 启用本仓附带 addon（v1.10+）；必要时 `blender_viewport(op="restart")` |
| `main-thread-busy` | 主线程被渲染 / 模态操作占住 | 等它空下来，或改走无头 |
| 后端不可用（9877 连不上） | 后端进程没起来 | `blender_viewport(op="start")` |
| 写操作 409 `leased` | 别的会话持有写租约 | `blender_viewport(op="who")`，别强抢 |
| 工具数不是 15 / catalog 不是 34-228 | 插件版本旧或升级后没重启 | 安装 **v2.6.2** → **重启 DSH** → 复核 |
| `value is not lossless JSON` | 宿主与插件回执契约不匹配（旧版/未重载） | 升级到 v2.6.2 后**重启 DSH** |
| N 面板没有「Selection → DSH」 | addon 不是本仓 v1.10+ | 停用旧 addon → 重新安装/启用本仓附带 addon（v1.10）→ 重启 DSH |

## 6. 装完自检（可选，不需要 Blender）

~~~bash
npm test                              # 离线自检全绿
node tests/host_routes_selftest.mjs   # /host 路由 + selection S1–S3（需要后端在跑；scene-items 需 Blender）
~~~

## 7. 不在支持范围（请如实转达）

- **landmark / 人脸**：需要 cv2 / MediaPipe，**未安装**，不做人脸/关键点能力；
- **OCR、DXF**：未提供；
- **Open3D / manifold3d / glTF-Validator**：依赖未安装，相关校验/重建能力不可用；
- catalog 的「不覆盖声明」同时写明：生物/有机造型、电影级布光/体积/合成、角色动画绑定不在本插件覆盖范围。
