# 曲面算法（surface）

> 纯 `bpy + numpy` 的参数化曲面候选包：**规格 → 网格 → 质检 → GLB**。
> 不依赖 OCCT / geomdl / trimesh，随插件发布，GUI 与无头都能跑。

## 1. 它解决什么

硬表面用 Box/Bevel 就够了，但"有曲率、要顺、要按截面变化"的形体（车壳过渡面、瓶身、头盔、罩壳）
用布尔/雕刻很难稳定复现。surface 把这类形体变成**可复算的规格**：

- 同一 spec（含 tessellation）→ 同一个 `spec_hash` + 同一批顶点（可复现，不是手工捏）；
- 生成后立刻跑 `surface_validate` 拿 `pass / fail / degraded` 三态；
- 需要看图时导出 GLB，用外部查看器/交付链路看，**不必为了看一眼先渲染三视图**。

## 2. 什么时候用 / 别用

| 场景 | 用什么 |
|---|---|
| 截面放样（瓶身、罩壳、机身段） | `surface_loft` |
| 沿路径扫掠（管、梁、裙边、线缆走向） | `surface_sweep` |
| 四边面片（局部过渡、A 面补片） | `surface_patch` |
| 已有 spec 要落成网格 | `surface_tessellate` |
| 网格质量/连续性/自交/厚度体检 | `surface_validate` |
| 导出 GLB 给外部查看/交付 | `surface_export` |
| 基础体 / 分面硬表面 | 不要用 surface：`bmesh` / `geo` 基元 + Bevel |
| 有机/雕刻 | 不要用 surface：`sculpt_*` |
| 需要 G2/高阶 NURBS 或 CAD 级偏置 | 不要用 surface：M5 未实现，需要 OCCT 后端 |

## 3. op 一览

| op | 输入 | 输出 |
|---|---|---|
| `surface_loft` | `sections=[{z_mm, points_mm:[[x,y],...]}]`、`degree`、`continuity`、`closed`、`tessellation` | 网格对象 + `spec` + `spec_hash` |
| `surface_sweep` | `profile_mm`、`rail_mm`、`orientation`、`twist_deg`、`scale` | 同上（平行传输标架） |
| `surface_patch` | `control_grid`、`degree_u/degree_v` | 同上（张量积 B-spline 面片） |
| `surface_tessellate` | `spec_or_object`、`quality` | 网格对象（spec → 网格 / 对象 → 烘焙） |
| `surface_validate` | `spec_or_object` + 开关 | `verdict` / `metrics` / `checks` / `defects` / `next` |
| `surface_export` | `spec_or_object`、`out_dir`、`name` | GLB 文件路径/字节数 |
| `surface_blend` | `a, b, ...` | **ok:false**（M5，需 OCCT） |
| `surface_offset` | `spec_or_object, distance_mm` | **ok:false**（M5，需 OCCT） |
| `surface_fit` | — | **ok:false**（M3 接口保留，未实现） |
| `surface_selftest` / `surface_help` | 无参 | 真机自检 / 参数速查 |

## 4. SurfaceSpec（M0）

    {
      "kind": "loft | sweep | patch",
      "units": "mm",
      "degree": 3,                 // loft/patch 的基函数次数（1..7）
      "continuity": "G0 | G1 | G2", // 目标连续性（validate 按它判）
      "closed": true,              // 环向闭合（loft 的截面 / sweep 的剖面）
      "constraints": {             // 可选：validate 用
        "min_thickness_mm": 2.0,
        "max_curvature_1_per_mm": 0.5,
        "g1_tol_deg": 12.0,
        "g2_tol_ratio": 0.1
      },
      "tessellation": { "u": 32, "v": 24 }   // 或 quality: draft|normal|fine
    }

单位统一 mm：入参、回执、bbox 都是 mm；内部按 `scene.unit_settings.scale_length` 折算。

## 5. 最小链路（照抄）

    # 1) 放样
    op="surface_loft", args={
      sections: [
        {z_mm: 0,   points_mm: [[-60,-30],[60,-30],[60,30],[-60,30]]},
        {z_mm: 80,  points_mm: [[-52,-26],[52,-26],[52,26],[-52,26]]}
      ],
      degree: 2, continuity: "G1", closed: true,
      tessellation: {u: 24, v: 8}, name: "Cowl"
    }

    # 2) 转网格（拿 object 名，如 SURF_loft_ab12cd34）
    op="surface_tessellate", args={spec_or_object: <上一步的 spec>}

    # 3) 体检（fail 不静默成 pass）
    op="surface_validate", args={spec_or_object: "SURF_loft_ab12cd34"}

    # 4) 导出 GLB（外部查看/交付）
    op="surface_export", args={spec_or_object: "SURF_loft_ab12cd34", out_dir: "D:/out", name: "Cowl"}

## 6. validate 怎么读（最重要）

- `verdict=pass`：声明的连续性达标、无自交、闭合壳厚度达标、网格质量正常；
- `verdict=fail`：**确认缺陷**（自交 / G1 不连续 / 超曲率 / 翻转法线 / 退化面 / 厚度不足）；
- `verdict=degraded`：检查没跑成（三角数超 `max_tris`、射线量不到厚度等）—— **degraded ≠ 通过**；
- 开放曲面（patch）的厚度是 `n/a`，不是 fail；
- `defects[]` 每条带 `check / severity / msg`，`checks` 里是各项原始数字，`next` 给下一步建议。

## 7. 边界（如实）

- **M1 是插值型 B-spline 截面放样**：截面之间按 B-spline 过点，但 `z` 沿 v 线性；不是 NURBS 曲面；
- **G1/G2 连续性只在有缝的方向可查**（loft 的 section 缝、sweep 的闭合剖面接缝）；单张 patch 是 `n/a`；
- **曲率/厚度是离散近似**：对三角化密度敏感，不能当制造认证；
- **M3 fit 未实现**：没有参考图反推参数的求解器，先用 `shapesolve` / 手工参数；
- **M5 blend/offset 未实现**：明确返回 `ok:false`，要真正的 CAD 偏置/圆角需要 OCCT 后端；
- 大网格先 `tessellate` 降密度，validate 的自交是 BVH 暴力，超限会降级。

## 8. 和现有链路的配合

- 参考图比例：先用 `img_digest → img_probe/measure → img_calib` 量出 mm，再写 sections；
- 轮廓反推：`shapesolve_solve` 拟合尺寸后，把结果写成 surface spec 再生成；
- 验收：`surface_validate` 是单元级体检；项目级仍走 `gate_preflight / gate_run`（三态）；
- 交付：`surface_export` 出 GLB，装配/交付走 `asm_export / deliver_export`；
- 视觉：要看效果用 `qc_render_views` / `visualreport_report`（同机位才可比）。
