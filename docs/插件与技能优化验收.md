## 7.2 本轮做了什么（Lead 的硬约束 + 两处最小修）

**Lead 的否决（本轮约束）**：**`pass + skipped ⇒ pass` 作废**。必需门 `no_clash` 缺来源被 `skipped` 时，
**顶层必须 `degraded`、`ok=false`**；不为“健康默认预设”变绿而降低标准。

**F8-a · `_aggregate` 最小修（`runtime/gate.py`，`GATE_VERSION 2 → 3`）**
- 新口径：任一 `fail`/`error` ⇒ `fail`；**否则任一 `skipped` 或 `degraded` ⇒ `degraded`**；只有“存在真 `pass`
  且无上述任何状态”才 `pass`（空包也 `degraded`）。
- **保留** `coverage`（`checked`/`skipped`/`all_gates_ran`/`checked_ids`/`skipped_ids`）、`overrides` 与
  `overrides_applied`、`skipped[]`、`degraded[]`、`failed[]`；`skipped_note` 现在明说“会把顶层判成 degraded”。
- preset 语义随之明确：assembly 的 `no_clash` 未配置来源 ⇒ `skipped` ⇒ **默认 preset 顶层 `degraded`**；
  要 pass 走 `overrides={"no_clash":{objects_a:[…],objects_b:[…]}}` 或自写 spec。
- 该结论在两处文本同步：`gate.py` 模块 docstring + `gate_run` docstring + `gate_plan` note + `gate_help`。

**F8-b · print preset 的分辨率假通过（`runtime/gate.py`）**
- **先验证真实字段**：`print_report` 顶层只有 `ok/walls_ok/overhang_ok/thin_samples_total/worst_min_mm/
  worst_p05_mm/params/detail`；“`min_mm` 低于本网格测量分辨率 ⇒ 结论不可信”**只**写在
  `detail.walls.objects[].warning` / `resolution_mm`（`print_walls` 里 `thr_mm < res_mm` 时设）——
  旧 `pass_if="thin_samples_total == 0 and walls_ok == True"` 完全看不见它 ⇒ **粗网格上“根本没量得出来”会读成绿**。
- 修法（不改 `printcheck.py`，全部落在 `gate.py`）：新增 spec 键 **`degrade_if`**（受限表达式，与 `pass_if`
  共用 AST 白名单与变量解析）与 **`echo`**（点路径取真实字段）。print preset 现在带
