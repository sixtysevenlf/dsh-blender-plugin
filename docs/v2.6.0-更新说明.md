# v2.6.0 更新说明

> 发布：2026-10-21 · 插件 **v2.6.0** · addon **v1.10 / protocol 11** · **15 个模型工具** ·
> plan catalog **33 family / 217 op**（其中 **97 个只读**）
> 下载：[GitHub Release v2.6.0](https://github.com/sixtysevenlf/dsh-blender-plugin/releases/tag/v2.6.0) ·
> 完整记录：[CHANGELOG.md](../CHANGELOG.md)

## 一句话

这一版的主题是 **GUI 优先、无头备用**：默认先开 GUI；无头只是备用，但能力完整——不开 Blender 窗口也能建模、看帧、
验收、交付；能力面从 **28 family / 186 op** 扩到 **33 / 217**，模型工具仍是 **15 个**（新增能力全部走
`blender_rt_plan` 的 catalog，不增加模型要记的工具名）。

## 升级三步

1. **更新 DSH 插件到 v2.6.0 → 重启 DSH**（插件是 DSH 启动时加载的模块，不重启不生效）。
2. **Blender addon 不用动**：本版未改 addon，已装 v1.10 的继续用；旧 `MCP for Blender` 自 v2.3 起不支持。
3. **验收**：
   - `blender_rt_plan(op="catalog")` → **33 family / 217 op**，工具数 **15**
   - GUI 在时 `curl -sS http://127.0.0.1:9877/doctor` → `kind=ok`
   - 纯无头：`blender_rt_worker(op="start")` + `op="see"` 回一帧图即自证（此时 doctor 的 bpy 往返不可达属预期）

## 为什么值得升

| 以前的限制 | 现在 |
|---|---|
| 看一帧、跑一段 Python 都得先开着 Blender 窗口 | 常驻无头会话：`worker start` 之后 `see` 约 50–100 ms 一帧，`exec` 毫秒级 |
| 长渲染 / 长作业超时就把结果丢了 | 作业层 `rt_job` + 台账对账：后端重启后按磁盘证据恢复 `done/failed`，不再一律判 `stale` |
| 「像不像参考图」只能靠肉眼 | 参考图量具 `img_*`（量尺寸 / 轮廓 / 孔 / 对称）+ 同机位 QC `visualreport_report`（verdict-first） |
| 装配穿模、浮块、间隙靠感觉 | `asm_scan` 全对全分类（clash / contact / gap / float / contained / unresolved）+ 修复与导出 |
| 交付前没有硬门 | `gate_*` + `deliver_export(require_gate=true)`：不过门不写盘 |

## 新能力（按使用场景）

### 1. GUI 优先；不开窗口也能干活（备用）

> 默认先开 GUI Blender + Connect；以下无头能力是无 GUI / 批处理 / 长活时的备用路径。

- `blender_rt_worker`：`start / exec / see / watch / reset / stop`，支持 `preload`、`warmup`、空闲 TTL（默认 15 min）
- `blender_rt_do` / `blender_rt_see`：传 `session` 或 `auto` 自动降级到无头 worker
- `blender_rt_plan(..., session="auto")`：按 family 自动起持久 worker 并 dispatch，不依赖 GUI
- `blender_rt_watch(session=...)`：无头逐帧采样 + hash，判断「动没动 / 对不对」

### 2. 按参考图还原

- `img_digest`：原生分辨率量测、轮廓、Hough、孔、对称、可读性，输出可确认的数字表
- `img_probe` / `img_measure` / `img_calib`：探针、量距、标定
- `shapesolve_solve`：从二/三视图轮廓反推尺寸（正交解析投影 + numpy 光栅化，不渲染）

### 3. 装配与交付

- `asm_scan` → `asm_manifest` → `asm_merge`（merge 前自动 gate + snapshot）
- `asm_repair(policy=safe|manual|aggressive)`：safe 只做 translate/snap、硬禁布尔；默认 dry-run
- `asm_export`：GLB / FBX / OBJ + `manifest.json` + append-only `merge_ledger.jsonl`
- `gate_preflight` / `gate_checkpoint` / `gate_deliver` + `deliver_export(require_gate=true)`

### 4. 白模与参考包

- `blockout_base / batch / export`：声明式 parts、mm / anchor、Workbench 3 视图、GLB
- `blockout_refsheet`：4 正交/透视 PNG + 2×2 拼图 + `refsheet.json`
- `blockout_turntable`：Blender 内置 FFMPEG 出 MP4/H264 转台

### 5. 验收与评估

- `visualreport_report`：同机位 QC，verdict-first，qc → imgtools → numpy 三级降级
- `eval_run`：缺陷注入 / 基线评估，缺模块的用例标记 `skipped` / `degraded`，不假通过

## 稳定性与正确性

- **台账以文件为准**（`runtime/recover.mjs`）：后端重启/被杀后先做磁盘对账（`summary.json` → 产物 → stdout 终态），
  能对上就返回 `done|failed` + `recovered:true` + 证据，不再让模型自己去 `Get-Process` / `ls` 破案。
- **多灯卫生**：识别 `Shadow buffer full (N / M)`，给出结构化 warning（`eevee_shadow_pool_full`）与 `K.light_hygiene`。
- **进度通道**：`dsh_progress(**fields)` / `DSH_PROGRESS` 与 stage 分开，长阶段不再「看起来卡住」。
- **写作用域两维**：`blender_viewport op="lease" scope="collection:COL_Lights,prefix:LGT-"`，`/who` 与 409 回执都可见；
  配套 `K.route_collections()` 按前缀归位。

## 修复

- **issue #32**：Windows 上 `npm test` 在 `tests/linux_selftest.mjs` 处链式中断
  （ESM 动态 import 用了裸路径 `C:\…`，被当成协议名）→ 改 `pathToFileURL(...).href`。
- **issue #33**：`tests/workdir_shared_selftest.mjs` 的 C5 在 Windows 恒红
  （用 `path.sep` 切 POSIX 风格路径，Windows 上根本不切）→ 改 `path.posix.basename(...)`。
- **文档口径**：改正「`/host/view/*`、`/host/pick*`、`/host/ready` 路由为兼容保留」的错误表述 ——
  这些路由在 v2.3 已随面板删除，现存宿主路由只有 `/host/selection`、`/host/scene-items`、`/host/jobs`。

## 文档与 skill

- README（中英）、操作教程、配置参考、安装/部署/迁移、AGENTS、CLAUDE 全量对齐 v2.6 口径，
  清掉 28/186、v2.5、v0.9.x 与「必须 GUI」的旧说法。
- 随包 skill 改为「架构优先」主线：catalog → plan op → worker session → 回执 / verdict → 门 / 交付；
  新增工具选择矩阵、标准状态机、P0–P2 配方与反模式，通用 Blender 知识降为附录。

## 兼容性

| 项 | 说明 |
|---|---|
| Blender addon | **v1.10 / protocol 11**，本版未改；旧 `MCP for Blender` 不支持 |
| 模型工具数 | 仍是 **15 个**，入参/回执保持向后兼容（只增字段） |
| DSH 侧面板 | v2.3 起已删除；选中入口在 Blender 原生选中 → `N` 面板「发送选中到 DSH」 |
| GUI | 仍完全支持；只是**不再是必需项** |
| 升级 | 更新插件后**重启 DSH**；只改后端才用 `blender_viewport(op="restart")` |

## 不覆盖 / 未安装依赖

landmark / 人脸（无 cv2、MediaPipe）、OCR、DXF、Open3D / manifold3d / glTF-Validator **均未安装**；
生物与有机精细造型、电影级布光 / 体积 / 合成、角色动画绑定**不覆盖**。不要按「已支持」使用。
