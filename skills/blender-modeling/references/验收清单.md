## 任务模板（直接复制给验证子代理）

你是**独立验证者**，不是构建者。只读本文件 + 我给你的回执与图。

- 输入：`spec`=<规格文件路径或期望数值>｜`回执`=<gate.json 路径或粘贴>｜`图`=<1–2 张同机位渲染图>｜`变更`=<改动的对象/文件清单>
- 要求：
  1. **数值门自己跑**（下表），不许采信构建者的结论；
  2. **关键项必须换一条计算通路**（见下"反 Goodhart"）；
  3. 按"输出格式"回 **4 行**，不要复述构建历史、不要重跑全场景体检；
  4. 证据不足就写 `unresolved`，**禁止**在证据不足时二选一硬判。

## 数值门（脚本跑，别交给模型）

| 验什么 | 调用（都走 `blender_rt_plan`） | 通过判据 |
|---|---|---|
| 单件网格健康 | `op="audit_mesh", args={objects:[…], summary_only:true}` | `state=pass`（= `verdict`）且 boundary / nonmanifold / degenerate / loose_verts / loose_edges 全 0；法线看 `normals_state=pass`（**逐壳**判，别只看总 `signed_volume`） |
| 全场景最脏 | `op="audit_scene", args={summary_only:true, top_k:5, self_intersect:true}` | `state=pass`；★ **不传 `self_intersect:true` 时默认跳过自交检查 ⇒ 只能给 `degraded`**，那不是通过；否则只看 worst 的 score |
| 装配连通（浮块） | `op="audit_connectivity", args={scope:"COL_Geo"}` | ★ 顶层**没有** `state` —— 读 `gate.state=pass`（或 `gate.verdict`）且 `floaters=[]`；`degraded` **不等于**通过；**别拿"分量数=1"当判据**（贴而未焊天然是多分量） |
| 干涉 / 重叠（三角级） | `op="audit_interference"` / `op="audit_overlap"` | `audit_interference.volume_mm3 ≈ 0` 且 `verdict="refuted"`；`unresolved` **不等于**通过（采样不够就判不了）；`analyzed=false` ≠ 无重叠；⚠ **贴合会给出 `pair_count ≥ 1` 与 `unresolved`** —— 设计接触要白名单化，别拿 `pair_count` 当穿模开关；**没给两侧来源时门记 `skipped` —— 跳过不是通过（见下面第 4 条）** |
| **展示拼接交叠** | `op="audit_measure", args={objects:[…], neighbors:true}` | 按项目接口表 `overlap_mm` 复核；`axis_overlap_mm` 仅在接口法线与世界轴一致且几何适用时作粗筛。旋转接口沿真实接口局部坐标量测表面，并复查浮空/异常互穿；不据此判结构连接强度 |
| 形状漂移 | `op="audit_drift"` | chamfer ≤ 约定阈值（默认口径 ≈ 最长边 2.5%） |
| 打印初筛 | `op="print_report", args={min_mm:…, max_angle_deg:45}` | `thin_samples_total=0` 且 `walls_ok=true`，并检查 `detail.walls.objects[]` 的分辨率/警告；阈值低于测量分辨率时结论不可信。`gate_run(preset="print")` 默认只查活动对象并会因此降级，多对象需逐件指定；这不构成完整制造认证 |
| 交付完整性 | `op="deliver_verify"` | md5 清单齐全、单位盒归一化、贴图随包 |
| UV / 材质 | `op="uv_stats"` / `op="material_scan"` | 有 UV 层且零面积 UV 面=0；材质非空、procedural 项已 bake |

回执太大时先瘦身：`summary_only:true`、`top_k:N`（实测 40 对象场景 9,176 → 1,148 字符，判定不变）。

**四条口径陷阱（否则会把结论读反）**：

- ★ **三态，不是二态**：`audit_mesh` / `audit_scene` 顶层 `state`（= `verdict`）∈ `pass` / `fail` / `degraded`。
  **`clean=false` 有两种成因**：`fail`（确有缺陷，看 `totals` 里非 0 的字段）或 `degraded`（**没查完/判不出来**：
  自交检查被跳过（`self_intersect=false`）或抛异常、`normals_state=unknown`、逐壳分析超面数上限）。
  ⇒ 见到 `clean=false` **先读 `state` 与 `reason`**：`degraded` 要**补查**（`self_intersect=true` 重跑 / 看 `normals_reason`），
  **不许**当"没过"也不许当"过了"；`ok=false`、`analyzed=false` 同理都不是通过。
  法线也别只看聚合 `signed_volume`：它把**所有壳相加**，大正向壳 + 分离的小反向壳仍可能为正 ⇒ 看 `normals_state` 与 `normals_shells[]`（逐壳 `state`/`nested`），**`unknown` 一律不给 pass**（无其它缺陷时 `degraded`，有缺陷时 `fail`）。
- `audit_measure` 的 `axis_overlap_mm` 是**逐轴 AABB 重叠**（回执自带 `note: "bbox 级（不是三角级）"`）。
  仅在接口法线与世界轴一致且几何适用时可作粗筛；旋转接口必须在真实接口局部坐标中量测表面。
  全内含浮块也可能给出三轴正重叠，须结合连通与干涉检查；`volume_mm3` 是交集体积，不能代替接口深度或结构强度。
- `audit_mesh` 读**未求值**的 `ob.data`：未 apply 的修改器不算数；装配级 `audit_*` 走**求值网格**。两者别混。
- ★ **门包（`gate_run`/`gate_plan`）的顶层只看 `verdict` 三态**：`ok` 只在**每一门都真跑过且都过**时为 `true`。
  **任一门 `skipped` 或 `degraded` ⇒ 顶层 `degraded`（fail 优先）** —— `skipped` = 未配置来源 / 该门不适用
  （如 assembly preset 的 `no_clash` 没给两侧 objects），**跳过 ≠ 通过**：默认 `gate_run(preset="assembly")`
  判 `degraded` 是**正确行为**，要 pass 必须补 `overrides={门id:{args…}}` 或自己写 spec；
  回执 `coverage.all_gates_ran=false` 与 `skipped[]` 就是"哪些门没跑"的自证。
  同理 **判据为真 ≠ 证据可信**：`degrade_if` 命中（如 `print_report` 的 `min_mm` 低于测量分辨率
  `resolution_mm`）把该门判 `degraded`，回执 `echo` 里的真实字段就是降级证据。

## 反 Goodhart：什么叫"换一条计算通路"

同一件事**不许**用构建时那条通路复核。判据：换通路后，若构建逻辑本身有 bug，结论会翻转。

- 构建用 `Object.dimensions`（局部 bbox × scale，**不含旋转**）⇒ 验证用 `matrix_world @ v.co` 求世界 AABB；
- 构建用内环 score ⇒ 验证换独立脚本/独立 op 复算，不读内环的 best；
- 构建用导出器自检 ⇒ 验证用 `deliver_verify` 对 md5 与单位盒；
- 构建说"看起来对" ⇒ 验证必须给**数值 + 画面**两条证据（缺一不可）。

## 主观门（只有这类需要陌生视角）

"像不像参考图 / 构图 / 配色 / 排版 / 文案"：先用 `qc_render_views(ref_path=…)` + `qc_compare` 拿数值
（IoU / 剖面差），再由你看图下结论。**图 ≤2 张**，不要全场景重渲；主体占画面 <5% 的图直接判无效重拍。

> ⚠ **IoU 只是"该视图下轮廓重合度"**，是**必要不充分**条件。它看不见：深度/厚度、内部特征
> （板缝/格栅/灯/特征线位置）、曲面张力（面感）、其他视图。而且"把轮廓填满"就能刷高它。
> ⇒ 见到"IoU 0.9"**不要**直接判 pass：至少要求**多个视图各自算** + 一张特征线对照（`parts_color`）+
> `clear_check` 间隙；发现"IoU 涨了但图更难看了"就判 `unresolved` 并指出是哪一层错
> （包络 / 站表 / 特征线）。

```
failures: <不达标项 ≤3 条：对象 / 字段 / 实测值 / 阈值>

```

## 自查（跑偏的信号）
