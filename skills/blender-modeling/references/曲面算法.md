# 曲面算法参考（surface_*）

纯 bpy + numpy 的参数化曲面：spec → 网格 → 质检 → GLB。无 OCCT 依赖。

## 1. 何时用

- 截面放样：瓶身、罩壳、机身段、车顶过渡 → surface_loft
- 沿路径扫掠：管、梁、裙边、线缆走向 → surface_sweep
- 四边补片：A 面过渡、局部曲面 → surface_patch
- 已有 spec 落网格 → surface_tessellate
- 网格体检（连续性/曲率/自交/厚度） → surface_validate
- 导出 GLB 给外部查看/交付 → surface_export

基本体/分面硬表面用 bmesh/geo+Bevel；有机用 sculpt_*；需要 G2/CAD 偏置不要用本族。

## 2. op 与关键参数

| op | 关键参数 | 说明 |
|---|---|---|
| surface_loft | sections=[{z_mm, points_mm:[[x,y]...]}]、degree(1..7)、continuity(G0/G1/G2)、closed、tessellation{u,v} | 插值型 B-spline 过截面；z 沿 v 线性 |
| surface_sweep | profile_mm、rail_mm、orientation(auto/up_z/up_y/fixed)、twist_deg、scale | 平行传输标架 + 累积 twist + 逐点 scale |
| surface_patch | control_grid（规则网格）、degree_u/degree_v | 张量积 clamped B-spline 面片 |
| surface_tessellate | spec_or_object、quality(draft/normal/fine) | spec→网格；对象→烘焙求值网格 |
| surface_validate | spec_or_object + continuity/curvature/self_intersection/thickness 开关 | 返回 verdict/metrics/checks/defects/next |
| surface_export | spec_or_object、out_dir、name | 导 GLB；返回 path/bytes/tris |
| surface_blend / surface_offset | — | M5 未实现：明确 ok:false（需 OCCT） |
| surface_fit | — | M3 未实现：接口保留 |
| surface_selftest / surface_help | 无参 | 真机自检 / 参数速查 |

## 3. 单位与可复现

- 所有长度 mm；内部按 scene.unit_settings.scale_length 折算；
- 同 spec（含 tessellation）⇒ spec_hash 相同、顶点一致（无随机数、不用 bpy.ops）；
- 对象名不影响 spec_hash。

## 4. verdict 三态

- pass：声明连续性达标、无自交、闭合壳厚度达标、网格质量正常；
- fail：确认缺陷（自交/G1 不连续/超曲率/翻转法线/退化面/厚度不足）；
- degraded：检查没跑成（超 max_tris、厚度量不到）—— **degraded 不等于通过**；
- 开放曲面厚度 n/a，不是 fail；defects[] 逐条给 check/severity/msg。

## 5. 最小链路

    surface_loft(sections=[...], degree=2, closed=true, tessellation={u:24,v:8}, name="Cowl")
      → surface_tessellate(spec_or_object=<spec>)        # 拿 object 名
      → surface_validate(spec_or_object=<object>)        # 读 verdict
      → surface_export(spec_or_object=<object>, out_dir="D:/out", name="Cowl")

## 6. 限制（如实）

- 截面之间是 B-spline 插值，但 z 沿 v 线性；不是 NURBS 曲面；
- 连续性只在有缝方向可查（loft section 缝 / sweep 闭合接缝）；单张 patch 为 n/a；
- 曲率/厚度是离散近似，对三角化密度敏感；
- M3 fit、M5 blend/offset 未实现；高级圆角/偏置需 OCCT 后端；
- 大网格先降密度，自交检查超限会 degraded。

## 7. 配合

- 比例：img_digest → probe/measure → calib 先量 mm；
- 轮廓：shapesolve_solve 反推尺寸后再写 spec；
- 项目验收：surface_validate 是单元体检，最终走 gate_*（三态）；
- 视觉：qc_render_views / visualreport_report 同机位对比。
